# Contributing to AutoAura

Thanks for your interest in contributing to **AutoAura**, an AI-powered vehicle health assistant built with Microsoft Copilot Studio!

We welcome all kinds of contributions, including:

- 🛠 Feature ideas or enhancements
- 🐞 Bug reports
- 📚 Documentation improvements
- 🔌 Plugin suggestions
- 🧪 Use-case testing or feedback

## Getting Started

1. Fork the repository and create your branch:
   ```bash
   git checkout -b feature/YourFeatureName
   ```

2. Commit your changes with clear messages.

3. Push to your forked repo and open a **pull request** on the `main` branch.

4. Provide a detailed explanation of your change in the PR.

## Guidelines

- Keep commits small and focused.
- Include screenshots or examples for UI/UX changes.
- Ensure that your changes do not break existing flows.
- Align with the conversational flow and UX of Microsoft Copilot Studio agents.

## Questions or Suggestions?

Feel free to [open an issue](https://github.com/thumurohit/autoaura-copilot/issues) or reach out via GitHub Discussions.

Happy contributing! 🚀
